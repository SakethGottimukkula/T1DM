    Prediction models

    CGM-only forecasts use the existing OhioT1DM XGBoost models. Multimodal forecasts use separate models trained on SimGlucose virtual-patient data with CGM, past insulin, and optional carbohydrate features.

    Research prototype using simulated data; not a treatment recommendation. Only CGM, past insulin, and meal carbohydrate values are model inputs. Simulator risk metrics are excluded.
